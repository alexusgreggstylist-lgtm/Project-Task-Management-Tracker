# Project Task Management Tracker
A Google Sheets project tracker and dashboard for monitoring task status, deadlines, overdue tasks, and overall project progress.
Overview

This project is a sample task management tracker built in Google Sheets to organize tasks, monitor deadlines, and summarize project progress.

Project Goals

Organize tasks across multiple projects.

Track task owners, priorities, start dates, and due dates.

Identify overdue tasks and tasks due today.

Summarize project progress in a dashboard.

Tools Used

Google Sheets

Spreadsheet formulas

Conditional formatting

Charts and dashboard design

Skills Demonstrated

Data organization and tracking

IF and COUNTIF formulas

Counting records with COUNTA

Deadline monitoring

KPI reporting

Data visualization

Dashboard Metrics

The dashboard summarizes total tasks, completed tasks, tasks in progress, overdue tasks, and the overall completion rate. A chart shows the distribution of tasks by status.

What I Learned

I practiced transforming a task list into a structured tracking tool and dashboard. I learned how formulas can automate status reporting and how visual summaries can make project information easier to interpret.

Data Disclaimer

This is a practice portfolio project using fictional sample task data. It was created to demonstrate spreadsheet and reporting skills.
