# Project & Task Management Tracker

A Google Sheets project designed to organize tasks, track deadlines, identify overdue work, and monitor project progress through a dashboard.

## Open the Project

-  **Google Sheets version (best for interactive review):** [Open the live spreadsheet](https://docs.google.com/spreadsheets/d/1MgU8ODBGBDN3iaLGT1GVZZedIRFO47eg7gOhNrazJfE/edit?usp=sharing)
- **PDF portfolio report:** [View or download the PDF]Project & Task Management Tracker.pdf
- **Excel workbook:** [View or download the Excel workbook]


## Project Features

- Task tracking across multiple projects
- Task priorities, owners, and due dates
- Automatic overdue alerts
- Days remaining until deadlines
- Dashboard with key performance indicators
- Chart showing task status

## Tools & Skills

- Google Sheets
- IF, COUNTIF, and COUNTA formulas
- Conditional formatting
- KPI reporting and dashboard design
